The ten steps as a swimlane. Each lane is a role, each box names the screen the work is done on.

Reading the loops: every "No" goes back to the person who raised the work, never forward. A rejected plan line returns to the requestor, a failed validation blocks submission, a rejected requisition comes back for correction, and a deliverable the second reviewer won't accept goes back to the coordinator. Step 5 has no owner action — the sourcing case is created by the system the moment the requisition clears its approvals.
